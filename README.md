# Smart Route

Prototipo móvil de alta fidelidad para la planeación inteligente de rutas logísticas.

## Descripción

Smart Route permite planificar rutas teniendo en cuenta variables como:

- Peso y dimensiones de la carga
- Restricciones viales
- Horarios de circulación
- Altura de puentes
- Ancho de las vías
- Características del vehículo

## Objetivo

Ayudar a pequeñas y medianas empresas transportistas a reducir costos,
optimizar recursos y mejorar el cumplimiento de los tiempos de entrega.

## Slogan

Rutas inteligentes, decisiones eficientes.
